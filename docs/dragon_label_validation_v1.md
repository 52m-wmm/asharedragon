# 历史龙头标签有限验证 v1

执行日期：2026-11-07（America/Los_Angeles）。范围固定为五个指定案例，以及2021—2025每年×主板/创业板/科创板各一个随机抽取的**预测负例候选**，共20个窗口、162个股票交易日。没有全市场行情补采，没有修改行情、旧标签、数据库或UI。

## 1. 结论

- 重建成功候选只有10个，不等于历史只有10个龙头。重建总体仅有15段观测高度≥5的片段，其中5段首板边界未知；10段有可定位首板，其中8段完整、2段仅确认条件下限。它还受主板历史ST缺失、特殊状态及参考价未验证的选择影响。
- 圣龙14板、艾艾13板在旧重建总体中均被ST未知挡住；现有独立证据路径已正确识别，不需要额外猜测ST。本轮不是新增这两个标签。
- 九安、中通、克来在旧重建总体均缺席，但不能因著名案例身份直接记为FN。九安/中通缺可严格逐日定位的收盘证据；克来旧公告存在基准日歧义。本轮新查到克来2024-02-05明确收盘涨停的公告，只在验证包中增加1日参考证据，不升级为13板事实。
- 15个随机预测负例都缺独立首板真值，不能认证为TN。两例已知正例在旧重建端均是unknown而非明确预测失败。Precision/条件Recall均为NULL；不以小样本估算全市场准确率。
- 本轮未发现需要修改现有标签引擎的确定性错误；不降低门槛。旧版额外五日窗口排除问题已在v0.7修复，240个样本已恢复，未重复计入本轮收益。新增完整周期及生产标签均为0。

## 2. 两套总体不是同一基准

## 7. 是否需要购买更多数据

需要的是独立可追溯的历史收盘涨停/限价及边界证据，不是更多相同OHLC。此次15个对照无法取得可靠真值，已经说明只有名股公告不足以验证普通失败样本；但本轮并未证明一定要付费购买。

先使用已有免费官方公告/合法独立来源对**预先固定**的年份×制度窗口进行小规模验收；若供应商可提供正负样本、ST/特殊状态、真实参考价、覆盖完整性及授权，可要求试用验证这些固定窗口。只有试用能同时减少普通样本unknown、恢复真实正例且不制造FP，才有理由购买。禁止仅凭著名龙头被补出来就认为产品可信，也不要为提高样本数把主板历史ST默认成非ST。
