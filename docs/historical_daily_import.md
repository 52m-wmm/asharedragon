## 2. 格式、字段与口径

源文件按交易日期存放，例如 `1d_price/YYYYMMDD.parquet`；每文件包含当日多只股票。日期为 `YYYYMMDD` 字符串，无分钟时间；代码是保留前导零的 `000001.SZ` / `600000.SH` 字符串。已抽样 2017、2020、2022、2024、2025、2026 年，并对全部目标文件执行同一结构和质量检查。

| 原字段 | 输出字段 | 处理 |
| --- | --- | --- |
| code | stock_code | 保留完整字符串和交易所后缀；拒绝指数、基金、B 股或未知代码模式 |
| date | trade_date | 严格转换为 Arrow/DuckDB DATE，验证内部日期 |
| open/high/low/close | 同名 | 保留原值，不实施复权 |
| vol | volume | 原值，单位股 |
| amount | amount | 原值，单位人民币元 |
| ZIP 身份 | source | `purchased_usb_0dfebf6ee9bc`，不同源不覆盖 |
| 验货结论 | adjustment_type | 发布后 `none`；未核验 staging 为 `unknown` |
| pre_close/adj_factor/vwap | 同名附加字段 | 原值保留以供后续审计 |

`change`、`pct_chg` 和 Pandas 行索引不纳入标准化研究表，原 ZIP 保留可追溯。未编造历史 ST、停牌、封板时间、上市日、缺失价格或数量。

**复权和单位判定依据是本地实测，而非 ZIP 文件名或供应商说明**：4,381 条 BaoStock 未复权重叠日线 OHLC、成交量、成交额一致，17,772 条 Tushare 事件收盘价和金额一致；全量收盘价均符合分币精度，全部 `amount / volume` 与 `vwap` 一致，且 VWAP 均位于当日高低价内（容差 0.02 元）。据此判定当前 OHLC 为未复权、成交量为股、金额为元。未得到供应商字段说明，独立对照覆盖主要为 2020—2025 年，不能据此声称每个历史值都经外部核验。`adj_factor` 是独立因子，不乘入 OHLC；公司行动完整性和因子基准尚未认证。

## 5. 与现有数据源的重叠核验

只读取本地 PostgreSQL，审计事务设置为 `READ ONLY`，没有网络补采。日线对照使用各来源/代码/日期/复权口径的最新既有版本；Tushare 从既有 `raw_observations` 的 `limit_list_d` 原始记录提取收盘价，不把事件表里的空 `limit_price` 当价格。

- BaoStock：2021 年 978、2022 年 453、2023 年 1,004、2024 年 1,514、2025 年 432，共 4,381 条重叠。OHLC 差异 0（阈值 0.011 元），收盘价最大差值 0；量差超过 1 股为 0，金额差超过 max(1 元, 对照值×1e-6) 为 0。
- Tushare 本地事件：2020 年 17,772 条重叠，收盘价差异 0、金额差异 0。事件样本有选择偏差，不代表全年全部个股逐条认证。
- AKShare：2024 年 22 条重叠，价格、金额差异 0；21 条量差超过 1 股，差值范围 −42—+47 股，比例接近 1。项目 AKShare 适配器将手数乘 100，此差异与手数展示/舍入精度相符，未将任何源判为错误，未覆盖原值。
- 2017、2018、2019、2026 年缺少本地独立价格重叠证据。没有为追求核验覆盖而调用付费代理。

五只重点股票已全范围检查；BaoStock 本地没有这些股票的重叠日线，Tushare 可核验 2020 年的 36 条事件，全部一致：

每只股票逐年记录数及首末日期、完整缺失交易日列表、各源年度核验结果保存在本地 `audit.json`。

## 6. 存储与断点续传

正式目录：

```text
~/Datasets/asharedragon/processed/stocks/daily/purchased_usb_0dfebf6ee9bc/
  manifest.json
  audit.json
  year=2024/month=01/daily.parquet
  ...
```

在年月分区上增加来源目录，避免未来不同来源无条件覆盖。111 个正式 Parquet，每月一个、ZSTD 压缩、按代码/日期排序，逻辑总大小 **265,667,274 字节（253.36 MiB）**。隔离 staging 的 111 个 Parquet 合计 **440,964,144 字节（420.54 MiB）**；保留用于审计和恢复。`du -sk` 实测：正式目录 259,708 KiB、staging 431,536 KiB，总计约 **675.04 MiB**（含清单/审计）。无额外 ZIP 副本、无 DuckDB 服务器或数据库备份。

每次只读一个日文件，每月输出一个分区，DuckDB 内存上限 512 MB、2 线程，单 ZIP 成员限制 32 MiB。Arrow/Python 另有开销，512 MB 是 DuckDB 配置上限，未宣称整个进程的实测峰值。每批前检查可用空间，最低保留 2 GiB。

ZIP 不调用 `extract`/`extractall`，拒绝绝对路径、`..`、反斜杠、符号链接、未知成员格式，不执行其中程序。临时 `.partial` 文件在异常时清理，硬中断遗留文件在对应批次恢复时删除。文件写完且质量检查通过才原子重命名，进度 JSON 原子替换；并发运行使用文件锁。严重异常只暂停受影响月份，正式发布要求没有暂停批次。

源 ZIP 以 SHA-256 标识；完成月份以内容哈希验证后跳过。验货审计绑定各月哈希，发布前重新核对，正式文件也有独立哈希。实际完成转换后重新执行恢复流程，验证 111 个完成月份跳过；发布流程再次执行也未重复生成分区。未测试强制断电，代码具备中断恢复路径，不等于实测所有崩溃窗口。

新增三个本地脚本：`scripts/import_historical_daily.py`（验货转换）、`scripts/audit_historical_daily.py`（本地对照）、`scripts/release_historical_daily.py`（证据门槛及发布）；研究入口为 `backend/app/research/daily.py`，拒绝未验证 staging，不会自动将新源混入旧源。

```python
from pathlib import Path
from app.research.daily import connect_daily

path = Path.home() / 'Datasets/asharedragon/processed/stocks/daily/purchased_usb_0dfebf6ee9bc'
with connect_daily(path) as db:
    summary = db.sql('''
        SELECT year(trade_date) AS year,
               count(DISTINCT stock_code) AS stocks, count(*) AS rows

```

正式分区查询实测（本机、2 线程、512 MB、文件缓存可能已热，单次测量不是 SLA）：年度 count/avg 聚合约 **0.046 秒**；九安医疗 2,230 条历史的 20 条观测成交量窗口约 **0.070 秒**。窗口基于已有观测行，不能在有停牌或缺行时把 20 条观测直接当作 20 个交易所交易日。

PostgreSQL 继续保存原有事件、标签、聚合结果；本轮没有新增或覆盖这些事实。日线留在 Parquet，由 DuckDB 直接查询，未实施大规模 SQL 导入。

## 8. 研究就绪程度与后续工作

**可开展范围受限的沪深量价探索**：按代码查询历史、构建候选首板前量价窗口、结合已有事件做探索性月份分布。已有未复权价格不能单独构成完整涨停/连板研究数据集，更不能证明龙头标签成立。

正式重建涨停和连板前，必须接合历史 ST 状态、上市/退市日期、停复牌和特殊交易制度，核实 `pre_close` 的除权除息参考口径；沿用现有保守规则，未知仍标未知。**不得用复权价格判断涨停**，也不能将上一条记录收盘价简单当当天涨停参考价。首板前 5/10/20 日特征需按交易日历定义缺失和停牌，避免窗口跨缺口。未来收益和最大回撤要先验证因子及公司行动、可交易性和退市结果，原始 OHLC 涨跌不能无条件当可投资收益。

剩余优先事项：

1. 补充 2026-03-16—2026-11-06 及后续日线，独立核验后以清楚来源接入。
2. 补北交所，或将研究范围明确固定为沪深 A 股；本包不能称全市场。
3. 获取供应商字段说明和复权因子基准，补 2017—2019、2026 的独立对照；校验已退市股票全集和逐日有效证券目录。
4. 补历史 ST/停复牌/IPO 特殊状态及除权参考价，才执行全量涨停连板重建。
5. 在通过上述门槛后，定义龙头标签、普通首板对照组和严格时间切片，计算收益/回撤；本轮未开发这些后续研究任务。
