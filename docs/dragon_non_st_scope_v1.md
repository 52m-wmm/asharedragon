# 龙头研究范围：历史非ST、非退市整理期 v1

执行日期：2026-11-07（America/Los_Angeles）。这是研究资格版本变更，不是行情或历史涨停事实修订。历史ST仅作为资格输入，不再建立独立ST研究目标；本轮没有采集ST数据、调用付费接口或写入PostgreSQL。

## 1. 新口径与重要限制

研究窗口中的明确ST、*ST、历史SST/S*ST或退市整理期日期排除研究，不计成功或失败。历史状态未知保持unknown。普通名称、当前名称、成交量>0、BaoStock tradestatus=1均不能单独证明历史非ST及非退市整理期。

- 涨停事实与研究资格独立：可信直接收盘事件继续成立，不重复要求ST来“证明涨停”。但该事件本身不是非ST证明。
- 可信、逐证券日期、经审核的正常交易制度证据可直接用于资格，不再重复请求同一ST证据。例如在ST与普通主板限幅不同的历史制度内，独立确认的普通10%制度可替代重复ST验证。创业板/科创板20%制度及ST与普通股限幅相同的时期不能这样推断。
- 当前没有已归档、可直接用于本研究资格的完整正常交易制度证明。现有strict历史规则发布为空，旧特殊状态为unknown；`tradestatus=1`仅区分交易/停牌，不能当作“非退市整理期”证书。
- 本地713个采样股票日已有明确非ST观察；独立总体442个窗口、重建总体619个窗口的所需日期都有非ST观察，但缺非退市整理期/正常制度的完整证明，仍属资格unknown。**这部分不需要重复补ST，而需要解决另一资格字段。** 不把没有退市标记的普通名称或数据库未记载退市日期当作全量历史无退市整理期证明。
- 正常制度证明只影响研究资格，不制造涨停事件、官方限价或历史首次可获得时间。来源冲突保留；出现可信ST/退市证据时保守排除，记录冲突，不以普通制度证据覆盖它。

因此，新口径当前没有通过完整资格的成功/失败对照。0表示符合新资格的已验收样本为0，不表示历史不存在非ST龙头，更不撤销原76个成功事实或71个完整成功周期。

### 资格作用日期与不回写原则

二元成功只核验首板起已证明的前5个涨停日期，不要求之后未知终点；后来变ST不能倒过来否定已经具备资格的5板结果。失败核验该已结束短周期的计数日期。unknown片段不虚构首板。精确最高高度及完整周期列表使用全部已观察涨停日期的资格；它与五板二元结局独立。

前后非涨停边界是用于确认周期的历史事实，不是买入研究日；不因边界本身ST就重复要求该日非ST。缺资格日期不能被跳过并拼接两段涨停，也不把排除日期生成失败或新首板。

新记录同时保留`historical_outcome`、`research_outcome`、`eligibility`、`cycle_eligibility`与逐日缺口。接口只在返回的研究视图中将资格unknown的结果标为unknown，未修改原JSON/Parquet或历史事实表。

## 4. 确定的资格解析修正

日期对应的历史简称`XR*ST安`、`XR*ST莲`、`XD*ST经`在旧时间轴中因前缀而保持unknown。研究过滤器现在先处理XR/XD/DR除权除息前缀，再识别明确ST/*ST；明确“退”标记作为退市整理期排除证据。名称仅作带日期属性，关联仍为标准股票代码、交易日期和稳定证券ID。不会根据今天名称回推历史，更不会因普通简称没有ST字符而自动生成非ST事实。

[Tushare limit_list_d官方说明](https://tushare.pro/document/2?doc_id=298)称不统计ST，但本地历史响应含上述ST简称及退市整理股票。因存在实际反例，未将接口合同当作整个股票池的非ST或非退市资格证明；仅查阅公开文档，没有调用Tushare接口。原始归档保留。

本次所需21,668个股票日期中明确排除88日：ST相关82、退市标记6；其余21,580日资格未完整。股票日与周期计数不能直接相加或比较成覆盖率。
