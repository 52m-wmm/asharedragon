# AShareDragon v0.7：历史样本覆盖与首板特征可用性

本轮完成本地证据盘点、周期二元结局修复、T+1盘前时点分层、年度统一样本、描述性重算与现有研究UI接入。**没有恢复2021—2025年的新成功/失败样本**：本地缺少独立正向涨停或真实限价证据，不能由已有日线和ST状态推测填充。跨年份代表性问题尚未解除。

固定版本 `dragon-research-v0.7`，快照 `49bfba76ba9a1247695e`。现有10,343,963条日线、原始购买文件、PostgreSQL业务记录均未修改；没有市场数据网络采集、付费接口调用或GitHub Push。

## 1. 为什么样本集中于2020年

逐层核对未过滤PG原始响应、标准化业务记录、磁盘归档、父证据快照及事件选择代码，未发现隐藏的2021—2025年涨停归档被查询年份过滤掉。事件读取范围跨2017—2026年，集中现象主要是已成功保存的来源覆盖造成的。

- PG `limit_list_d`原始成功响应中的17,772条记录均属于2020年；标准化涨停事件表也只有2020与2026记录。
- 检查831个磁盘JSON文件，其中823个属于涨跌停归档，8个为检查点；按内部交易日期统计48,007条重复归档记录全部属于2020年。此数包含重复版本，不能当作独立事件数量。
- 可用事件池覆盖2020年148个交易日、2026年9个交易日。2020-04-24的一组字段异常仍隔离；未为扩大样本而解除来源质量限制。
- 2023、2024各有一个通过公司公告交叉验证的已知案例。2021、2022、2025没有可用独立正向事件；已有负向证据不能独立产生首板。
- `proxy_facts`无历史`stk_limit`、`stock_st`、`daily_basic`等补充事实；本地重建限价是推导结果，不能冒充独立官方限价验证自己。
- 已保存BaoStock成功原始记录：2021年978条、2022年453条、2023年1,008条、2024年1,536条、2025年432条。它们含历史交易/ST及部分估值字段，不等于独立收盘涨停事件。
- 统一状态层仍保留75,461条观察，包含重复来源和unknown记录，不是75,461个全部已验证ST股票日。日线、交易状态、风险警示状态和涨停事实继续分离。

官方接口说明也限定`limit_list_d`的历史范围与ST统计范围，因此不能把该来源的无记录视为未涨停，尤其不能以它代表2017—2019全市场。[Tushare涨跌停列表说明](https://tushare.pro/document/2?doc_id=298)

### 240个排除样本与5个成功片段

- 另5个2020年周期：首板与连续5板已证实，但最终周期终点未知。现可纳入“达到5板”的二元成功结果；精确最高高度仍NULL，不升级为完整周期。
- 其余2,935个候选继续unknown，其中2,751个首板边界未知、184个首板已确认但未来结局未确定。不得归为失败。
- 完整局部周期仍5,369个，其中71个完整周期≥5板；新二元对照组为76成功、5,298失败，共5,374。标签目标是“这个已确认首板周期是否达到5板”，不是“未来五日任意一次涨停”或最终精确最高高度。

### 每年的最小修复范围

2021、2022、2025的第一优先级是同一连续交易区间内的独立收盘涨停事件或官方涨跌停参考价，不是重复下载OHLC。2023、2024也需要覆盖普通首板失败组的同类证据，继续只核验著名成功案例会强化选择偏差。

可行的下一次数据补充单元：预先固定每年一个连续20–40个交易日的窗口及必要左右边界，覆盖窗口内所有候选证券，记录真实来源范围（特别是ST、创业板与科创板）。起点前至少一个可确认边界日，达到5板的观察过程或提前结束证据均须完整；仍处涨停状态的边界继续向外延伸，不强制推断终点。先选择已有状态/行情能够交叉核验的区间，但不可按最终赢家选择股票。没有独立正向事件前，单独扩大负向规则范围无法恢复成功与失败对照。

## 3. T+1盘前可用性分层

新决策截止是下一**交易所交易日**北京时间09:25，严格小于；UTC通常为01:25。使用已审计交易日历跨周末、节假日寻找下一交易日；日历末端不猜测截止日期。

每个字段分别存储：`historical_event_at_utc`（事实发生/日终确定时间）、`collected_at_utc`（实际原响应采集时间）、`first_available_at_utc`（有独立证据时才填写首次可获得时间）、`availability_upper_bound_utc`及证据ID。盘前已有的真实采集记录只证明“最迟此时已获得”，不冒充首次发布时间。

严格纳入需要：可信值，事实在截止前发生，并有带证据的首次发布时间或截止前真实采集记录。后来的历史回填不证明当时不可用，归类为“历史可用时间未核验”，其真实值仍进入探索层。已经核验的较早发布时间可以让较晚回填数据通过时点门槛，回归测试覆盖该路径。不能只用现在文档的一般更新时段回推十年前每条记录的实际发布时间。

例如官方每日指标说明给出常规日内更新时段，但这不构成本地每个历史字段的逐条版本与发布时间证明，也不能移用到不同来源的首封时间或封单字段。[Tushare每日指标说明](https://tushare.pro/document/2?doc_id=32)

本地当前没有一条**已解结局研究样本**的候选名单形成与字段历史时点同时得到严格证明，因此严格研究资格为0。字段的事实时间满足T+1决策逻辑，但首次可用时间仍未知；这不是宣称这些字段在历史上无法获得。

### 新出现的差异及其不确定性

- **首封时间**：成功74个、失败5,268个；中位09:57:20对10:52:02.5，成功组早约54.71分钟。Cliff δ = −0.306，证券聚类95%区间[−0.442,−0.173]，日期聚类[−0.438,−0.155]。每证券最早周期敏感性对照的有效N为29/2,309，BH q≈0.0010。
- **封单金额**：成功74个、失败5,298个；中位3,879.48万元对2,583.84万元，差约1,295.63万元。Cliff δ = 0.273，证券聚类95%区间[0.155,0.397]，日期聚类[0.154,0.392]；单证券有效N为29/2,326，BH q≈0.0010。
- **流通市值**：中位33.70亿元对41.39亿元，δ约−0.129，单证券BH q≈0.538，不能称为稳健差异。换手率5.615%对6.0%，δ约−0.073，q≈0.308。
- 首板成交额、前置量价等虽有部分描述性差异，本轮14项检验校正后没有达到相同显著性门槛。

两项较强的差异在本地样本、去重及聚类敏感性下存在，但**不等于跨年份稳健发现**。字段是在放宽到允许日终事实的探索层才可分析，仍不能用于严格时点回测或宣称盈利因果机制。

### 推断边界

使用2,356个稳定证券ID处理多周期相关性；每证券最早周期敏感性样本2,356个，30成功/2,326失败。分别按证券、首板日期做1,000次聚类bootstrap，固定随机种子600071；两者不是双向联合区间，也未完全处理窗口跨日依赖。
14项预设特征的单证券双侧Mann–Whitney U使用BH校正；区间未另做多重比较校正。单证券检验仍受不同证券共同市场冲击影响，交互筛选产生的额外比较也不由这14项校正覆盖。没有通过过采样平衡类别；未知没有算失败。候选发现依赖来源覆盖和公告案例选择，没有足够已知入选概率做代表性加权。
