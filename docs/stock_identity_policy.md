# 股票身份与上市退市日期口径

按用户确认，本地 `research/stocks.parquet` 的上市、退市日期作为研究主口径。
统一快照直接复制该目录表，覆盖统计按其上市、退市区间计算；外部核对结果不自动覆盖本地日期。
未提供日期时保留缺失，不根据第一条或最后一条行情编造上市、退市日期。

股票使用带交易所后缀的代码（如 `600537.SH`）关联，保留前导零。
股票名称用于展示，不作为跨来源关联键。历史 ST 状态按股票代码与交易日记录，不能从当前名称回填历史。

上市退市对比页已撤下，旧地址 `/data/lifecycle` 返回数据资产总览。
核对脚本及原始报告保留供追溯；本次确认本地口径不代表外部差异已全部核实。
