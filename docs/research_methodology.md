# 研究方法与时间泄漏边界

## 事实、信号、结果

三层必须分开：原始观测 → 当时可获得的研究特征 → 未来才确定的后验标签。连板数是源在该交易日提供的当前高度，不是该轮最终高度；最终高度、未来最大涨幅及未来题材归属不得进入首板当日特征。

所有数据都保存交易日期和采集时间。`available_at` 只有可核实的公开时间才能填；当前 AKShare 返回无法证明这一时间，因此 NULL。收盘研究也不能自动假设所有字段 15:00 可用。

`GET /api/research/snapshot?code=000001.SZ&trade_date=2024-01-03&as_of=2024-01-03T16:00:00%2B08:00`：

- strict（默认）：同时满足采集时间、公开时间、交易日期截断；公开时间未知的记录排除。当前回采历史不产生当时已可用证据，因此可能完全为空。
- collected：只证明本系统在 as_of 前持有该记录，仍不证明市场公开时间。所有事实先按截断过滤，再选择当时版本。
- 不返回 dragon_labels，不把今天补采的数据伪装成当年的观察日志。

## 市场情绪

按供应商宇宙独立计算，不声称覆盖交易所全市场。

- 炸板率 = 炸板数 /（涨停数 + 炸板数）。任一池缺失或总数为零：NULL。
- 二板晋级率 = 昨日首板名单中今日恰为二板的股票数 / 昨日首板股票数。
- 三板晋级率同理，从昨日二板名单追踪到今日三板。不是“今日三板数 / 昨日二板数”这种不核对股票身份的粗略比值。
- “昨日”是源交易日历中上一交易日，不是上一条非空记录，也不是上一自然日。
- 名单/高度缺失或分母为零：NULL。第一个采集日缺少上一日名单，晋级率为空是预期结果。
- 连板序列遇缺口返回未知，直到明确非涨停后重置；停牌是否保持连板应依据明确口径，不自行延续。

## 季节性

1. 首板：源当日连板高度为 1 的事件数，按当日月份。
2. 高连板：达到指定阈值，且有完整逐交易日证据回到高度 1，按该首板月份、股票/启动日去重。追溯不完整计入 unresolved，而不是按高点日期归类。
3. 龙头：仅显式的版本化后验标签。尚未商定定义，因此本版不会把全部高连板复制成龙头。

按月同时展示覆盖交易日，未覆盖月份为 NULL；已采集月份统计是样本内统计，不应直接解释为跨年发生概率。最高板高度另按观测月份统计，界面明确区分。标签版本固定查询；多个类型共享同一股票/启动日时不重复计数。

## 个股收益与回撤

`analytics.metrics.returns` 要求传入一致口径、经过公司行动处理且逐交易日对齐的价格序列。前 N 日收益需完整窗口；未来 N 日最高**收盘价**相对起始收盘价的涨幅需完整未来窗口（不含启动日）；20 日最大回撤计算启动日及随后 20 个收盘的运行高点回撤。缺少完整窗口返回 NULL，不把截尾样本当低收益。它不是日内最高价收益，也不是可实现收益。

当前只采集未复权价格用于事实展示，未建立公司行动与历史复权序列，故未把该函数批量写为龙头标签。封单强度可在完整的同日金额口径上定义；未决定分母前不输出一个看似确定的指标。

## 涨跌幅规则

优先读取源提供的当日涨停价。独立 fallback 使用 Decimal 和分精度四舍五入，需要当日板块、ST、上市交易日序号、注册制发行事实及特殊状态；未知则返回 NULL。

已编码及测试：主板常规 10%、已核实历史 ST 5%；创业板 2020-08-24 起含 ST 20%；科创板 20%；北交所自成立后常规 30%；注册制上市前五交易日及北交所上市首日不限幅。旧核准制首日、复牌特殊期、退市整理特殊期、除权参照价不充分时拒绝推算。主板 ST 在 2025-06-27 征求意见后尚未审计最终生效区间，默认拒绝外推，需官方历史价格或明确 verified_rate。

## 研究前的必要补全

历史退市股票全集、上市与停复牌状态、历史 ST、历史题材、公司行动、源覆盖与时间可用性。避免幸存者偏差、题材未来泄漏、复权锚定变化、标签截尾和仅采集涨停股导致的选择偏差。完整研究应定义未涨停对照样本与统一样本宇宙。
