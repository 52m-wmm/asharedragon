# AShareDragon v0.6：首板特征实证研究

本轮完成固定局部样本、时点受限的特征提取、统计接口及现有研究中心页面。结果全部属于探索性分析，标签为局部验证；没有任何完整年份通过正式总体研究验收。没有训练预测模型。

## 1. 样本锁定与标签口径

样本版本 `dragon-feature-v0.6`，不可变快照 `8646da017b09c2872b60`。父快照为 `dragon_v056/snapshots/20261108T044422935371Z`。

完整局部周期5,369个；冻结主对照组5,129个（71个达到5板，5,058个未达5板）。成功和失败都要求：精确首板、精确周期终点及最高高度通过局部证据验证，且首板起算五个交易日的观察状态完整。未来最高板数仅存放于结果证据，不进入特征命名空间。

差额240个周期并非周期结局未知：219个最高1板、17个最高2板、4个最高3板，终点均已确认。它们被额外五日窗口条件排除，其中202个缺1个状态日、23个缺2日、15个缺3日。这项要求对已经结束的短周期偏严格。本轮不修改原生产标签，保留5,129主样本，并用全部完整周期作敏感性比较：71成功、5,298失败。未证明边界完整的其他片段不进入失败组。

## 2. 特征时点与不可用字段

决策截止为首板交易日T的北京时间15:00，UTC 07:00，采用严格小于。不得将T日最终收盘统计伪装为收盘前输入。所有可计算量价窗口只用T−1及以前已结束的交易所交易日；不以股票有行的日期代替交易所日历。缺行、零/无效成交量、未复权口径不符均保留NULL，不解释为停牌或零收益。

- 流通市值、总市值、换手率、当日成交额、炸板次数、封单金额：历史最终日终值不满足收盘前条件，严格特征全部NULL。已有5,127条流通市值与换手率归档保存在独立审计空间，没有回填特征。未对其他归档字段进行全量提取，不能把“未纳入特征”解释为原始源中一定没有字段。
- PE、PB：无已验证的历史收盘前估值快照；NULL，不使用当前估值。
- 首封时间：事件时间早于收盘不等于历史接口当时已发布；没有可验证的发布时间证据，严格特征NULL。
- 当日全市场涨停数量、最高连板高度：既缺收盘前可用证明，也缺完整市场覆盖。市场情绪分组不输出虚假比例。
- 前5/10/20日真实收益：公司行为、分红和总收益口径未经认证，NULL。额外给出明确命名的“未复权原价变化”，不冒充复权收益。
- 原价变化：C(T−1)/C(T−N−1)−1，要求N+1个日历交易日都有有效价格，并逐日核对pre_close与前日close差不超过0.011。发现参考价断裂则NULL；没有发现断裂仍不等于公司行为已完全认证。
- 成交量变化：前N个交易日均量 / 再往前N个交易日均量 −1，要求连续2N个日历交易日正成交量。不是首板当日放量，也不排除送转等公司行为对股数的机械影响。

每个量价字段保存窗口日期、行情来源和最后交易事件UTC时间。历史采集时间不冒充历史发布时间：这些是按事件时间有序的历史修订观测，`vendor_pit_verified=false`。因此可作探索性回溯描述，不能声称已构建供应商严格点时版本的交易回测特征。本轮没有引入当前市值或题材替代值。

### 统计方法与局限

- 中位数及25%/75%分位数按字段非空样本计算，不补值，不通过过采样平衡71:5,058。字段缺失本身可能有选择偏差。
- Cliff δ = P(成功值>失败值) − P(成功值<失败值)，并列值贡献0。正值不代表因果效应。
- 固定seed=600071、1,000次聚类bootstrap，分别按证券和首板日期整簇重抽样，使用2.5%/97.5%分位区间。两种单向聚类分别展示，不声称双向联合控制；窗口重叠带来的跨日序列依赖仍未完整处理。
- 比例区间要求至少5个含成功的簇和5个含失败的簇；否则不估计bootstrap区间，避免全成功/全失败小样本产生误导的零宽区间。Wilson独立样本参考区间保留在API，不作为主要区间。
- 每证券最早周期的双侧Mann–Whitney U仅作敏感性检验，六项预设量价指标共同进行Benjamini–Hochberg校正。跨证券的共同市场冲击仍可能影响其独立性假设。不是对中位数相等的专门检验。
- 分组阈值在统计前固定：原价变化−10%、0、10%、20%；成交量变化−50%、0、50%、100%。不根据成功率寻找最佳阈值。交互式筛选和月份比较均为探索性，q不提供对用户所有筛选路径的整体错误率保证。

方法参考：[SciPy Mann–Whitney U文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.mannwhitneyu.html)，[Cameron与Miller：聚类稳健推断](https://cameron.econ.ucdavis.edu/research/Cameron_Miller_JHR_2015.pdf)。

## 7. 验收与下一步

227项测试通过；前端生产构建通过。回归包含：首板日/未来行情不进入窗口、缺行不填零、参考价断裂、重复证券敏感性、bootstrap可复现、制度改革日期、接口筛选和快照完整性。既有Starlette/pandas弃用警告仍在，未产生测试失败。
页面实测：桌面与390px移动布局、成功/失败统计、创业板筛选、月份筛选、无样本板块及年份空状态；页面级无横向溢出。ECharts实际图表已渲染。冷读默认快照约0.11秒、创业板首次重算约0.41秒（本机单次测量，不是负载基准）。

当前不具备开展可靠样本外预测实验的条件：缺少代表性的独立年份测试样本、历史点时特征未认证、重要市值/估值/封板/情绪字段不可用，且特殊制度混杂尚未消除。本轮可交付的是可复现的探索性描述平台。
下一步应先明确研究决策时点：若研究问题确实在收盘后，应另建明确的收盘后样本版本及数据可用时延规则，而不是悄悄放宽本轮收盘前约束。随后优先补少量与现有样本对应的历史时点特征和独立时间对照区间，再预注册时间切分与检验方案；不必先补齐全部历史边界。
