# 美股跨市场研究数据模块

核验日期：2026-11-07。独立目录：`~/Datasets/asharedragon/cross_market/`。

QQQ已保存2017-01-03至2026-11-06共 **2,476个交易日**，与本次交易所日历一致，日线日期覆盖率100%。另外保留2016年12月21行预热数据，用于计算首个交易日收益。日线完整不代表历史发布版本、公司行动或A股事件完整。当前不能提供经过历史版本认证的预测结论。

## 数据源、价格与公司行动

主源为 [Nasdaq QQQ历史行情](https://www.nasdaq.com/market-activity/etf/qqq/historical) 的公开JSON接口：`https://api.nasdaq.com/api/quote/QQQ/historical?assetclass=etf&fromdate=2016-12-01&todate=2026-11-07&limit=9999`。以正常HTTP请求获取，未使用账号、付费代理或绕过访问限制。免费可访问不意味着获得再分发许可；原始响应和行情只保留本地。

使用现有AKShare的 `stock_us_daily(symbol='QQQ', adjust='')`（新浪原始行情）交叉核验。Yahoo探测返回429，Stooq返回HTML验证页面，均未作为数据输入。Nasdaq初次日期参数格式不符的响应也被拒绝，修正为ISO日期后才读取有效JSON。

保留USD原始OHLC、股数成交量、交易所日期、UTC会话时间、数据源、实际采集时间和价格口径；不制造复权收盘价。口径为 `provider_ohlc_no_cash_adjustment`：供应商未作现金分红调整的价格，不等同于已认证的全历史拆分账本。核验结果：

- 无重复日期、非交易日或无效OHLC。以0.011美元为跨源差异阈值，24日存在OHLC差异，其中24日开盘、1日最高、1日收盘存在差异。
- 2017-08-11收盘价：Nasdaq142.10、Sina142.08。保留主源原价和质量标记，涉及该收盘的两个相邻收益窗口均不进入实验。
- 2,086行成交量不同，最大差异18,616,461股。原因尚未可靠确认，不能简单归因于单位；保留Nasdaq原量与审计，不将成交量用于本轮预测。
- [Nasdaq分红数据](https://www.nasdaq.com/market-activity/etf/qqq/dividend-history) 保存目标范围40条现金派发。2023年有5条，包含12月27日每股0.21584美元特别分配，已与 [OCC公告53848](https://infomemo.theocc.com/infomemos?number=53848) 核对。
- 拆分调查未发现目标期内拆分，但没有取得发行方完整历史拆分账本，不能把“未发现”写成“已证实不存在”。供应商拆分列表只显示2000年的事件；详见[来源调查](us_market_sources.md)。

主信号 `price_return = close[t] / close[上一预期交易日] - 1`，不含分红。“隔夜”指A股开盘前获得的上一美国交易日信息，**不是美股开盘相对前收盘的隔夜跳空**。敏感性信号 `cash_entitlement_return_proxy = (close[t] + 当日除息现金金额) / close[上一预期交易日] - 1`，是现金权益计提代理，不是实际到账、再投资或税后总收益。未知公告时刻保留NULL；不使用未来锚定的复权因子。前一预期交易日缺失时不跨缺口计算收益。

## 时间对齐与历史版本限制

使用 `exchange_calendars==4.13.2` 的XNAS日历（库内映射XNYS），与实际QQQ日期逐日核验，包括夏令时、提前收盘、节假日和2025年1月9日特殊休市。保留 `America/New_York` 与本地交易日期；Parquet时间字段为带时区UTC，DuckDB会话显式固定UTC，API输出UTC偏移。

A股T日默认决策截止为 `09:30 Asia/Shanghai = 01:30 UTC`。在预期美国交易日历中选择“收盘后60分钟”的假定可用时间**严格早于**截止时刻的最后一场交易，再关联行情。若该场缺失则返回缺失，不回退到更旧的实际记录。美国标准时正常收盘21:00 UTC、夏令时20:00 UTC，提前收盘另按日历处理。例如A股2026-11-06开盘前关联美国11月5日，而非美国11月6日。

收盘后60分钟仅是市场时钟假设，**不是已核实的历史发布时刻**。2026年下载的最终历史行情可能经过后续修订，不能声称这些版本在2020年已取得。因此：

- 默认 `mode=strict`：来源实际观测时间必须早于截止；收益还检查前一收盘的来源时间。未满足则特征NULL，返回原因。A股滞后指标采用同样版本门槛。当前严格可用历史样本为 **0**。
- `mode=retrospective`：显式选择后才提供市场时钟对齐的历史诊断，标记 `retrospective_unverified_vintage`、`pit_verified=false`。不视为已认证的无泄漏回测。
- A股当日情绪单独放在 `outcomes`，标记 `outcomes_are_not_preopen_features=true`；日终可用代理为北京时间16:30。模型只用前序交易日指标，禁止当日结果混入开盘前特征。
- 当前数据对齐审计发现0条“假定可用时间不早于截止”的记录；这一检查不能替代历史版本认证。

## A股事件范围与缺口

仅对现有PostgreSQL做 `REPEATABLE READ READ ONLY` 快照读取；未调用Tushare网络。按来源分别检查采集分区完整性、行数、字段异常、重复和涨停/炸板冲突，不把缺少数据当成空池。

2389个A股交易日中，只有155日具备本轮可用的涨停和炸板事件池：既有Tushare代理历史池147日（2020年）及AKShare池8日（2026年）。2233日缺失完整池，1日存在重复事件。2020-04-24的Tushare涨停分区字段异常被排除。Tushare历史池有非ST范围限制，AKShare范围也不能无条件视为相同；两者不合并建模。以下都是**供应商可观察事件池指标**，不是重建后的全市场事实。

| 指标 | 可用日数 | 定义/限制 |
|---|---:|---|
| 涨停数量 | 155 | 完整U池中唯一股票数 |
| 首板数量 | 155 | 供应商连板数等于1，不生成正式首板或龙头标签 |
| 炸板率 | 155 | Z / (U + Z)，分母0为NULL |
| 二板晋级率 | 139 | 上一连续A股交易日首板队列中，当日观测为二板的比例 |
| 三板晋级率 | 149 | 上一连续A股交易日二板队列中，当日观测为三板的比例 |
| 科技行业涨停数 | 0 | 缺少可信历史有效期行业映射，全部NULL |

晋级仅使用同一来源、连续交易日的队列，不跨事件覆盖缺口；队列股票在当日或前一交易日有行情缺口时晋级率未知。供应商连板口径仍有历史范围及规则限制。没有用今天的行业分类倒填历史科技行业。

既有质量文件共125,036个历史股票交易日缺口，其中2026-03-16之后的 **1,790个**仍保留。`daily_missing_count` 随关联日期返回，未认定为停牌、未填零收益。现有120个A股行情Parquet均通过原manifest SHA-256复核；没有重导入或更改行情。

## 初步实验

只做描述统计及明确标记的回溯预测诊断。现有事件样本集中2020年且不连续；2026年仅8个完整事件日，不足拟合。以下为Tushare既有池，不能外推到整个2017—2026市场。

| 结果指标 | 配对样本 | QQQ价格收益Pearson | Spearman |
|---|---:|---:|---:|
| 涨停数量 | 147 | 0.0328 | 0.0501 |
| 首板数量 | 147 | 0.0108 | 0.0473 |
| 炸板率 | 147 | 0.2093 | 0.1165 |
| 二板晋级率 | 133 | -0.0080 | 0.0399 |
| 三板晋级率 | 142 | 0.0962 | 0.0330 |

对照模型只用上一A股交易日涨停数、首板数、炸板率及过去连续5个交易日涨停数量均值；增强模型加入QQQ上一美国交易日价格收益。固定ridge alpha=1，不搜索参数；按时间扩展训练，最少60个有效训练样本，均值/标准差只在训练窗拟合；训练标签的日终可用时间必须早于预测截止。来源不混用，配对模型使用相同测试日期。计数预测下限0，概率预测截断到[0,1]。另存历史均值预测基准。

| 预测结果 | 回溯样本外日数 | 仅A股MAE | A股+QQQ MAE | 相对A股基准增量R² |
|---|---:|---:|---:|---:|
| 涨停数量（只） | 72 | 17.0899 | 17.2051 | 0.00334 |
| 首板数量（只） | 72 | 14.5911 | 14.4673 | 0.00537 |
| 炸板率（比例） | 72 | 0.06857 | 0.06883 | -0.03592 |
| 二板晋级率（比例） | 63 | 0.06923 | 0.06943 | -0.00254 |
| 三板晋级率（比例） | 71 | 0.14178 | 0.14323 | -0.01721 |

样本外区间2020-04-13至12-31，二板从04-20开始，中间不连续。增量R²定义为 `1 - MSE增强 / MSE基准`，不是全样本拟合R²。现金权益收益敏感性结果同样保留：五项增量R²依次为0.00314、0.00525、-0.03584、-0.00266、-0.01698，没有选择更好的口径替代主结果。

结果未显示稳定增量预测价值：少数误差指标略有改善，其余退化，涨停数量的MSE微降但MAE上升。这里只呈现探索性比较，未作显著性或多重检验后的结论。**严格历史版本认证的预测样本为0，正式无未来版本泄漏的预测效果不可估计。**相关性不代表因果，更不代表可盈利策略。

## NQ期货可行性

已完成[官方来源调查](us_market_sources.md)。没有验证到可免费、可靠覆盖2017年至今的历史盘中来源，因此未接入NQ行情，开盘前价格明确NULL。

合约日线、近月、连续合约必须分别定义。连续合约需要明确映射、换月依据和差额/比例/不调整规则，不能当成实际可交易合约。CME Front与Active连续定义不同；不能用当天尚未结束的全日成交量决定早盘换月。公开结算页的发布时间也不等于结算价格形成时间，且历史结算规则有变更。可靠历史盘中报价可向CME DataMine或Databento评估付费范围，但本轮没有购买或调用。

北京时间09:30以前的NQ信息必须来自时间明确、在截止前已发布的合约报价或成交；期货当日收盘、最终日线和事后发布结算不能替代。后续若取得授权历史盘中数据，应保留UTC报价时刻、合约代码、映射生效时间、原价和调整规则，重新进行时点认证。

## 存储、接口与复现

`manifest.json` 原子指向独立快照 `snapshots/20261107T124223868595Z/`。本次活动快照含原始响应、5个主Parquet、审计和实验结果，共1,524,715字节（约1.45MiB）；开发阶段旧快照独立保留。原始响应及主Parquet都有哈希。成交量和价格不进入Git仓库。

- `qqq.parquet`、`qqq_actions.parquet`、`us_calendar.parquet`：原始日线、现金事件和交易时钟。
- `sentiment.parquet`、`aligned_diagnostics.parquet`：现有事件池聚合、缺口与回溯关联。
- `audit.json`、`event_evidence.json`：质量统计及来源证据。
- `experiments.json`、`diagnostic_predictions.parquet`：模型协议、描述统计及逐日诊断预测。

DuckDB直接读Parquet，内存限制256MB、2线程，不部署服务器。新增依赖exchange-calendars及其锁定依赖；pytz支持DuckDB带时区时间的Python读取。

| GET接口 | 用途 |
|---|---|
| `/api/research/us/qqq?start=2017-01-01&end=2026-11-06` | 原价、来源、时间与日期覆盖；原始行不能直接当开盘前特征 |
| `/api/research/us/association?start=2020-12-01&end=2020-12-31` | 默认严格时点保护，特征、结果、缺口分开返回 |
| 上述URL加 `&mode=retrospective&decision_time=09:30` | 明确选择未经历史版本认证的回溯关联 |
| `/api/research/us/experiments` | 已生成的描述与初步实验，不实时训练 |
| `/api/research/us/nq` | 返回不可用状态和NULL，不回退到日收盘 |

QQQ和关联接口支持page/page_size，单页最多1000行。无可信历史科技行业映射时返回NULL；未知和真实零值分开。当前构建脚本固定本次截止2026-11-06，后续扩展需更新范围并重新验证缓存覆盖，不能把已有缓存视为自动最新行情。

从项目根目录复现（优先复用已保存真实响应，创建新独立快照）：

```sh
PYTHONPATH=backend .venv/bin/python scripts/build_us_market_signals.py
PYTHONPATH=backend .venv/bin/python scripts/evaluate_us_market_signals.py
.venv/bin/python -m pytest backend/tests scripts -q
```
