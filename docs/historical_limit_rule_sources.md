## 价格计算、除权与特殊交易日

- 对有涨跌幅限制的交易日，以当日有效参考价乘 `(1+rate)` 计算涨停价，用十进制定点及四舍五入取最小报价单位。计算后与参考价差值小于一档时，按增加一档处理；不能直接使用二进制浮点比较或9.9%阈值。A股常规最小报价单位为0.01元。[证监会2019计算问答](https://www.csrc.gov.cn/guangdong/c105590/c1295922/content.shtml)、[深交所2011规则解读中的低价股例子](https://www.szse.cn/disclosure/notice/t20110118_500654.html)、[深交所2026规则第3.3.11—3.3.15条](https://docs.static.szse.cn/www/lawrules/rule/trade/W020260424690713155663.pdf)。
- 除权除息日以除权参考价作为涨跌幅基准。配股、送转、现金分红及经交易所同意的特殊计算公式都可能改变参考价；不能无条件用上一条真实收盘替代，也不能以未经认证的adj_factor生成参考价。[深交所2026规则第4.4.1—4.4.3条](https://docs.static.szse.cn/www/lawrules/rule/trade/W020260424690713155663.pdf)。
- 旧核准制IPO首日与普通10%涨停不同。上交所2014通知给出连续竞价有效申报上限为发行价144%，不是普通昨收×110%；缺发行价及对应历史制度时应unknown，不能一律当普通涨停或“完全没有价格上限”。[上交所2014原始通知](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20150912_3988761.shtml)。
- “恢复上市”“重新上市”不是普通复牌。**2020年12月样本中皇台酒业000995.SZ于2020-12-16恢复上市首日不设涨跌幅，12-17起为10%。** 这是与该月直接相关的已确认例外，不能仅靠最初上市日期排除。[交易所存档公司2020-088公告](https://disc.static.szse.cn/download/disc/disk02/finalpage/2020-12-15/03bcc8ea-5b2d-4b00-a2c1-74dd60c52484.PDF)。同类案例见[盐湖股份2021-08-10恢复上市公告](https://disc.static.szse.cn/download/disc/disk02/finalpage/2021-08-03/98aaca67-7c8d-4afb-bb61-e1aeaf7118f8.PDF)。
- 退市整理期制度有过渡安排。2020年底修订放开新制度退市整理首日限制，缩短整理期；不能将新制度无条件套给所有旧规则存量退市股。[上交所2020-12-31制度问答](https://star.sse.com.cn/star/media/news/c/c_20201231_5294529.shtml)、[深交所2020-12-31新闻发布会](https://www.szse.cn/aboutus/trends/conference/t20201231_584061.html)。创业板改革时，已进入且仍处退市整理的千山退300216、神雾退300156、盛运退300090仍10%，不能全体按20%。[深交所2020-08-21发布会](https://www.szse.cn/aboutus/trends/conference/t20200821_580925.html)。
- 停牌不等于普通负例；复牌是否例外须按当时公告/有效状态判定。仅凭“前一日缺行”不能断言停牌，亦不能断言当日普通复牌或重新上市。缺退市整理起始日、恢复/重新上市及其他特殊状态证据时，保留unknown是项目的保守选择，不是交易所规则本身。

上述资料可支持规则版本和特定边界用例；它们没有给出全市场逐日ST、暂停/恢复上市及退市整理名单，因此不能据此把所有2017—2026年记录都宣称“规则前提齐全”。

## Tushare对照集范围

[Tushare官方limit_list_d文档的机器可读版本](https://tushare.pro/wctapi/documents/298.md)明确其历史始于2020年、**不提供ST股票统计**，U/D/Z分别代表涨停/跌停/炸板，每次最大2500行。该接口是事件表，字段包括close、limit_times等，不是对全体股票逐日发布上下限价的 `stk_limit` 表。

由此得到的验证约束（项目推论）：

1. 已保存的U事件可作为该来源的真实正例；没有出现在完整U快照中，只有在当日股票确定属于该接口宇宙时才可当负例。ST及未知ST不能直接用“未出现”判为非涨停，也不能把ST规则重建正例直接算FP。
2. 验证前需检查完整日期、请求是否按单股或交易所过滤、分页截断、状态及重复版本。获取成功不自动等于覆盖完整。
3. 用事件close作为事件推导涨停价时必须标注来源；不能再把这同一事件当作独立价格验证真值，否则形成循环验证。
4. limit_times是供应商高度。与按连续交易所交易日重建的高度比较前，要说明停牌、IPO、左截尾和缺失数据的处理；不能用供应商高度填满unknown后再声称重建高度全匹配。
5. 小样本TP/FP/FN、Precision和Recall应明确共同可判定且在参考宇宙内的分母，并另列参考正例中的unknown/未覆盖数及捕获率。没有负例资格证据时，Precision应为不可估计，而不是只在正例集合中给出100%。

## 建议保留为unknown的情形

历史ST缺失且影响比例；当日限价或参考价来源不可信；IPO制度/上市交易序号不明；恢复/重新上市、退市整理及特殊事件未排除；日线或日历缺口；价格超过推导限价；两来源在价格、限价、事件类型或高度上存在未解决冲突。可信历史限价优先，但不能绕过停牌、无涨跌幅及来源冲突检查。

## 小样本发现后的补充：未股改S股票并非ST，也不适用普通10%

**非ST主板不必然等于10%。** 上交所[《关于对未股改股票实施差异化交易监管的通知》（上证发〔2014〕3号）](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/reform/c/c_20250520_10779478.shtml)明确未股改上市公司简称冠以S，价格涨跌幅限制为±5%；2014-01-07施行，替代2007旧通知。它是独立于风险警示ST的股票状态。深交所的[2007年原始通知](https://www.szse.cn/lawrules/rule/allrules/bussiness/t20101103_565178.html)也曾规定2007-01-08起未股改S股票统一5%，但该深市通知随后已因相关工作完成被列入废止清单，不能据此跨市场或跨时期无限外推。

对2020年12月的600182.SH，可串联以下公司原始证据：

- [公司2020-022公告原件（东方财富镜像）](https://pdf.dfcfw.com/pdf/H2_AN202007081390338214_1.pdf)：2020年7月终止当次股改筹划，7月9日复牌，简称仍为S佳通；终止筹划不等于完成股改。
- [公司官网2020年年度报告第6页](https://www.gititirecorp.com/corpfile/corp_202162205236782.pdf)：证券代码600182，股票简称S佳通。
- [公司2024-025监管函回复原件第7页](https://static.cninfo.com.cn/finalpage/2024-06-15/1220361194.PDF)：回顾2016/2017方案未获股东大会通过、2020年6月再次筹划而后终止，仍在推动股改。此为后续历史核验证据，不能作为2020年可用预测特征。

上述证据与本地保存的2020-12-03、12-24 Tushare U事件名称“S佳通”相符，因此这两条记录应按**未股改S股票5%规则**核验，不能因 `is_st=False` 就按10%认定为未涨停。这也解释了“不统计ST”的Tushare事件表中为何可以出现5%涨停股票：S与ST是不同状态。

实现建议：单独保留时点有效的 `share_reform_status` / 已验证限价比例证据；不要把S股票伪写成ST来凑5%。仅有代码或当前名称、无法确定该日股改状态时仍标unknown；不要把600182特例推广成“所有5%涨幅都是真涨停”，也不要把今天的S状态无条件倒填全部历史。
