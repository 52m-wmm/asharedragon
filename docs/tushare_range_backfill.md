## 完整性与恢复

- 优先周范围，不跨月；已经完整的日期不重新请求。仅 2020-12 基线核验是本轮明确授权的重复查询。
- 达到 2250 条（上限的 90%）即二分缩小范围。单日仍接近上限时，复用按 U/D/Z、交易所拆分；仍不能证明完整则暂停，绝不发布被截断的父响应。
- 要求返回日期属于请求交易日、每个预期交易日有记录、股票/状态有效、主键不重复；缺失日期递归缩小，单日空响应保持待核实。
- 全范围经过检查后，离线分解到交易日/状态，沿用已有 PostgreSQL 幂等分区入库。所有额外原始字段保持不变。
- 非空、已验证、未过滤的范围响应内某个状态缺席，与 API 整体返回空数组不同。前者仅记录“该来源范围响应中此类别无记录”，可保存零行分区；不伪造市场事件，不把它标成独立验证的市场零涨跌停。
- 完整原始 HTTP 响应先原子归档；离线分区明确标记 projection，保留真实源请求、原始响应路径与哈希，不冒充新 HTTP 响应。
- 中断后的 active_payload 可以离线重放；已完成日期跳过，未完成分区幂等恢复。历史 AKShare、BaoStock 不覆盖。
- 全局仍为最多 30 次/滚动 60 秒，至少 2 秒间隔（本入口为 3 秒）；文件锁禁止并发。IP 限流后 90 秒单次探测，连续第三次停止，窗口与次数不会随进程切换清空。
