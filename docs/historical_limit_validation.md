# 历史涨停规则与 L1 小样本验证

执行日期：2026-11-07（America/Los_Angeles）。规则版本：`historical-l1-v1`。仅使用已有本地行情、事件及免费官方规则/公告；没有调用行情或付费接口。

## 本轮验收结论

已实现证据门槛明确的涨停规则层、unknown原因、来源冲突处理、TP/FP/FN与覆盖率统计，以及带周期启动日期的客观L1标签生成器。**规则代码及小样本诊断已经完成，但没有任何完整年份或连续研究区间通过正式标签发布门槛，正式L1输出为0条。** 这不是没有涨停，而是目前不能把带假设的重建结果当正式事实。

两个验证层必须分开解读：

- **严格层**：缺历史特殊交易状态、可信参考价或必要上市/交易状态即unknown；独立历史涨停价优先。样本内的参考事件无法通过全部严格重建门槛，Precision/Recall为不可估计，不能写成100%。
- **诊断层**：用于发现规则错误和数据冲突。明确假设普通交易条件，2020年借助Tushare事件接口所属的非ST范围；这些条件不是独立完整历史状态。其指标仅针对明确记录的U/Z/D事件集合，不代表全市场表现，也不能授权正式L1。

原始Tushare/AKShare事件保留可用，供应商高度与独立重建高度分列。复权因子质量问题不会屏蔽不复权OHLC或已有事件。

## 1. 因子异常隔离

原始951万条日线和 `adj_factor` 均未修改。新增独立质量清单：

```text
~/Datasets/asharedragon/research/historical_limits_v1/
  factor_policy.json
  factor_anomalies.parquet
```

全量扫描生成 **29,465条待查因子记录**：因子变化且参考价未明显变化，或价格桥接残差超阈值的并集。与前次审计的28,932条和1,222条指标有交集，不能简单相加。清单保留原因子、前因子、原参考价和前收盘，并标记 `formal_factor_use_blocked=true`。这不是认定每条微小变化都错误；整个供应商因子字段仍未经认证。

研究API的metadata新增 `factor_policy`：禁止正式复权收益、复权均线和基于该因子的回测；不禁止raw OHLC及观察事件。规则层完全不读取因子；`require_certified_factors()` 明确拒绝未认证因子用途。已有通用SQL仍可审计原值，隔离是研究语义与计算入口限制，不是修改/删除字段或数据库权限封锁。

## 2. 规则与证据优先级

实现：[limit_rules.py](../backend/app/research/limit_rules.py)。一手资料和历史适用边界：[历史规则来源](historical_limit_rule_sources.md)。当前自动规则窗口限定2017-01-01—2026-11-07；北交所与未核实品种返回unknown。

优先顺序：

1. 检查日期、未复权口径、生命周期、停牌/无涨跌幅限制及来源冲突。可信历史限价也不能覆盖明确的无涨跌幅限制日；二者同时出现返回unknown。
2. 有带来源的可信历史涨停价格时优先采用；多个可信来源限价不一致返回unknown。正式限价字段不能由同一涨停事件的close或high冒充。
3. 否则，仅在历史状态、IPO交易序号、特殊交易日排除和除权参考价均已验证时派生。诊断模式可带假设试算，但输出始终 `formal_eligible=false`。
4. 保存的真实事件另列为观察证据，不能拿来填补重建结果后再对照自身。“未出现在榜单”不自动等于非涨停。价格/事件冲突保留记录，待核实，不修改任何来源。

| 场景 | 规则层行为 |
|---|---|
| 普通主板常规交易 | 10% |
| 主板ST/*ST | 2026-07-06前5%，当日起10%；2025-06-27是征求意见/准备日期，不是生效日 |
| 创业板 | 2020-08-24前普通10%、历史风险警示5%；当日起常规20%，含ST |
| 科创板 | 常规20%，含ST；不能套主板ST5% |
| 未股改S股票 | 经历史状态核实后单独按5%；S不等于ST，非ST也不一定10% |
| 注册制IPO | 科创板、2020-08-24起创业板IPO、2023-04-10起主板IPO前5个交易日no_limit |
| 旧核准制IPO首日 | 缺发行价/适用制度则unknown；不是普通10%，也不能一律称完全无价格上限 |
| 停牌/复牌 | 明确停牌可标suspended；未知不能从缺行猜测。已观察停牌后的复牌日缺特别规则时unknown |
| 恢复/重新上市、退市整理及过渡 | 缺历史特定证据返回unknown。退市前60自然日设保守回退门槛，不声称整个60日都是交易所特殊期 |
| 超限价、异常价格或来源冲突 | unknown，不能强行把异常日认定为涨停 |

计算使用Decimal，按0.01元、ROUND_HALF_UP取整并处理至少一档价格变化。参考价使用当日已经验证的除权除息基准，不使用上一条close或adj_factor反推。收盘封板要求close等于限价；high等于限价只表明触板。本轮不推断分钟路径、封板时间、排队成交或可交易收益。

项目原 `analytics/rules.py` 与 `analytics/reconstruction.py` 属旧版本兼容入口，原持久化结果未重写；本轮研究调用新版本，不把旧版较早的ST保守截止日期当制度生效日。历史重建结果不可混同新的正式L1。

## 3. 样本构造与防循环验证

### 2020年12月

- 23个交易日；使用成功、完整日期参数的已有Tushare快照，按原始快照ID隔离版本，保留来源哈希。
- U涨停1,039条、Z炸板367条、D跌停322条，共1,728条显式事件。Z/D作为参考负例，不把所有缺席股票判负。
- 价格来自已审计购买包的独立不复权OHLC。没有Tushare daily、stk_limit历史快照，也没有该月BaoStock历史ST/交易状态。
- 条件诊断用当日事件接口的非ST范围约束，不将它传播到缺少事件的其他日期；因此这不是独立历史ST验证，存在事件选择偏差。未股改S佳通另外处理。
- 全日期研究分母采用“实际价格记录 ∪ 本地已知上市生命周期证券 ∪ 参考事件”，不是认证的交易所历史全集。

### 2026年10月26日—11月4日

- 8个交易日；使用本地BaoStock不复权OHLC、pre_close、isST、tradestatus，对照独立AKShare已有U/Z/D事件。
- 这里使用的是后续本地日线，不冒称属于截至2026-03-13的购买包。
- 对同一代码/日期出现不同事件类型的参考记录先隔离，不能挑一个有利答案；名单、原因保存在冲突清单。
- 相对2020样本多了历史状态及来源参考价，但仍缺全覆盖特殊交易日排除证据，不能默认所有老股都是普通交易日。

两组均先独立按OHLC重建，再评分；不把事件close转成“官方涨停价”，不把 `limit_times` 用作连板起始种子。

## 5. 已发现并处理的问题

1. **未股改S特殊规则**：首轮600182.SH在2020-12-03、12-24按非ST10%会出现2个FN。核对上交所2014规定及公司2020原始材料，确认当时S佳通单独适用5%，修正规则后两条均匹配。没有把S伪标成ST，也没有用涨幅恰好5%倒推身份；后续公司材料只用于历史审计，不能当当时可用预测特征。
2. **炸板与收盘限价不一致**：2020样本11条、近期6条Z事件对应OHLC收盘恰好等于推导限价。原始字段支持这种不一致，不擅自改写为U。可能涉及快照时点或事件口径，尚未证明原因。最终观察合并状态为unknown_diagnostic_conflict；严格重建原本也是unknown。
3. **参考事件互相冲突**：近期有1个股票日不同类型事件同时存在，已剔出有确定答案的评分分母，另行保存，不能任意保留最后一种类型。

## 6. 客观 L1 的定义与正式发布门槛

实现的标签为：高度等于1/2/3时分别 `L1_1`、`L1_2`、`L1_3`；达到5/7/10板后分别带 `L1_5_plus`、`L1_7_plus`、`L1_10_plus`。阈值标签可以重叠，例如10板同时满足三个以上阈值。每条带 `cycle_start`、当日height、规则版本；逐日形成，不把未来最高高度倒贴给周期第一天。

本版连板定义为**连续交易所交易日收盘涨停**；明确停牌中断该定义的连续性，不采用“跳过停牌继续数板”。复牌第一日若状态未认证则unknown。该定义必须与未来研究或其他供应商口径区分。

`l1_labels()` 对每只股票的声明区间检查：

- 日期必须是完整、有序、无重复的交易所日历，逐日事实必须齐全，不能省略缺失日；不接受多股混在一个周期。
- 每日均通过严格规则，不能含诊断假设、unknown或来源冲突。
- 区间覆盖验收与独立规则验证均通过；仅日期齐全、仅与同源事件一致，不能放行。
- 左边界没有明确非涨停前序时，保留高度/启动日未知；直到遇到明确非涨停，再从下一次涨停建立首板。
- 当前验证运行没有任何获准区间，显式关闭正式发布资格，输出 `formal_l1_labels.json=[]`。模块已实现门槛和标签逻辑，后续通过证据验收的区间才可启用；不会根据“Precision很高”自动放开。

7板与10板逻辑已由合成单元测试覆盖，但本次真实可比样本最高只验证到6板，不能宣称7/10板获得真实样本认证。未给未通过区间生成“先用着”的正式标签，也未写 `dragon_labels` 或改旧版重建表。

### 哪些日期缺历史涨停价

本地没有独立 `stk_limit` 快照，购买包2017-01-03—2026-03-13 **全部2,230个有行情交易日期都缺独立历史限价覆盖**。具体日期与当天价格行数已完整保存为 `missing_historical_limit_dates.csv`；本次近期8个交易日同样缺独立限价，详见 `sample_coverage.csv`。319条炸板事件限价不能抵消这些日期级缺口。

独立限价缺失不意味着永远不能派生；在可信除权参考价和完整历史状态齐备且规则经过独立验证时可以派生。本轮这些替代条件也未全部满足。

### 哪些股票无法判断

本次两组全研究分母涉及 **5,437只至少一个股票日unknown的股票**，不是所有5,437只股票在所有日期都不可用。具体代码及unknown次数见 `unknown_stocks.csv`，具体日期、严格原因及诊断分类见 `unknown_stock_days.csv`。

2020年12月严格unknown 94,618个股票日：历史交易状态缺失94,104，日线缺失514；另1条皇台酒业2020-12-16由交易所存档公告确认恢复上市首日no_limit。近期严格unknown 41,735个股票日，主要缺特殊交易状态排除证据，另有复牌待查、退市窗口、缺日线及参考事件冲突。不能只给一份股票黑名单，而忽略状态会随日期变化。

## 8. 何时能够开始全历史识别

**现在可开始来源限定的真实涨停事件探索和规则诊断；尚不能开始正式全历史龙头标签生产。** 不给未经证据支持的完工日期。放行顺序为：

1. 先补/核验2020年12月的独立历史限价，或具有等效可信度的除权参考价及完整特殊状态；补历史ST、S股改状态、IPO序号、停复牌/恢复上市、退市整理制度信息。
2. 逐条解释本轮17条诊断Z/U不一致和1条参考类型冲突；不能通过删掉难例或用参考标签替换重建结果来验收。
3. 建立包含普通负例、ST、S、除权日、IPO边界、制度变更及退市/复牌样本的独立验证集；验证本文的事件集合有选择偏差，不能代表普通股票全市场FP率。
4. 取得连续完整日期、证券范围及每个连板前序的覆盖证明；起点左截尾不能用供应商高度倒推成正式起点。
5. 对经过认证的股票/区间逐段批准L1，再扩大到年度。历史日线日期齐全和高局部Precision本身均不是发布许可。
6. L1只是客观板数，不自动等于题材/趋势龙头。后续题材归属和量价特征还需时点一致数据；任何正式复权收益、复权均线与回测继续等待因子认证。
